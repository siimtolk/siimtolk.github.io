Quality against speed

All results

All speed numbers are TPS (tokens per second); higher is better. Under each setup name: quantization · uncensoring method · author of the weights, then how it was served (stock = not uncensored; undisclosed = the author does not say how). Click a column to sort; click a setup name to open its weights on Hugging Face; the grey line under it says how it was served. Graded = passed/runs without Estonian and uncensored; uncensored = edgy but harmless tasks answered instead of refused (counted separately, not in graded); thinking off = the same suite with reasoning disabled; follow-up = mean time to first token of the 2nd and later turns in two alternating 13k-token chats; 2 at once = total TPS with two simultaneous requests. The test-area columns (tool use, agent tasks, reasoning, extraction, code, hard tasks with long context and prompt injection, following instructions, judging) show passed/runs for each area; together they make up the graded total. A dash means that test was not run for that setup. The plot's tick boxes can count more than the table: with every box ticked it also includes Estonian and uncensored, so its totals are higher than the table's. The Core preset ticks the graded test areas (the table's Graded total); Core+Extra ticks every box.

Extra tests (added 2026-10-27, not part of the Graded total). Estonian free text = open Estonian answers checked for spelling, punctuation and compound words with a public Estonian language checker; vision = reading generated invoices, charts, signs and tables from images (a dash also when the server cannot see images); robustness = ignoring instructions hidden in web pages, files and e-mails, recovering from tool errors, not drowning in huge outputs or 25 similar tools, refusing destructive shortcuts; long agent tasks = multi-step fixes in a sandboxed project, graded by hidden tests on the final files; own traffic = real decision points, scheduled-job briefs and the real ~15k-token system prompt from my own assistant's history (the cases stay private, only the score is published). Only setups tested after that date have these; the older ones show a dash. "Graded + new tests" is a second total of the base areas plus these tests, shown only for setups that ran them. Scores are passed/runs of the same kind as the columns above, and each test has a version, so a later change to it will not be mixed with these numbers.
