# siimtolk.github.io

Personal blog, built by GitHub Pages (Jekyll, no theme gem: own layouts in `_layouts/`, styles in `assets/css/style.scss`).

New article: add `_posts/YYYY-MM-DD-slug.md` with front matter `layout: post`, `title`, `description`
(one or two sentences, shown on cards and in link previews), `tags`, and optionally `image` (card and
preview picture, stored under `assets/img/<slug>/`). It appears at `/articles/<slug>/`, on the home page,
on `/articles/` and in `/feed.xml`.
